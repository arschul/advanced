Advanced Hub Error Correction

TOEFL Error Correction

Ten pages, one grammar family each. Every page explains the patterns that cause the error, then drills them with thirty exercises — answerable on screen with instant feedback, or printable as a blank worksheet and a separate answer key.

How to use these. Each page opens with the patterns, written as wrong/right pairs. Work through those on the board, then set the exercises: Set A trains recognition, Set B uses the four-underlined-parts format from Structure & Written Expression, and Set C asks students to produce the correction themselves. Progress saves in the browser, so a student can stop and come back.
